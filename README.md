# Alexander Mong

Custom software and product-systems developer. I build product configurators, custom CPQ systems, and Unity/C# tools. Lately a lot of my work is about using AI as a real building tool while keeping a tight grip on what it produces.

For most of the past decade I ran a production Unity/WebGL shed configurator and custom CPQ system that handled thousands of quote, order, and rent-to-own records tied to millions of dollars in shed sales. Now I work with AI day to day, and I design the checks and source-tracing around it so the output holds up when someone digs into it.

### Featured work
**[Discourse-Spine](https://github.com/Alexander-Mong/Discourse-Spine)**: a Python method that pulls verifiable, source-traced findings out of long-form talks. It scores each candidate against pre-registered controls (including planted decoys it has to reject), and a person reviews everything it keeps before it counts.
