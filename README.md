# Alexander Mong

AI engineer and full-stack developer. I build agent systems and the checks that show when their output is wrong: agent loops with governed tool use, plain deterministic code on the paths where a model error would be dangerous, and evaluation harnesses with planted controls and predictions sealed before the run. I design the systems and gate what lands.

Before that I built and ran a production Unity/WebGL shed configurator and custom CPQ system for a decade. It processed 10,000+ quote, order, and rent-to-own transactions tied to tens of millions of dollars in shed sales.

### Public repos
- **[Discourse-Spine](https://github.com/Alexander-Mong/Discourse-Spine)**: a Python pipeline that pulls source-traced findings out of long-form talks. Each candidate is scored against planted controls it has to reject, and a person reviews everything it keeps. Runnable slice of a larger project; no API key needed.
- **[my-say](https://github.com/Alexander-Mong/my-say)**: on-device health intake on Gemma 4 through Ollama. The model can only select spans from what the patient said; deterministic code assembles the sheet and re-verifies every line. Built in two days leading a team of four at a hackathon at One World Trade Center; its limits are listed in its README.
